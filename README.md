# Hi, I'm Ant

I'm a design leader. I've spent the last decade building design practices in serious industries: the NHS, the MoD, AstraZeneca, GOV.UK and some of the big UK telcos. Mostly places where the work has to be right.

Right now I'm UCD Lead at NHS England, helping replace e-RS so the NHS can see secondary care patients sooner.

## What I've worked on

- **NHS England:** leading UCD on the move to a new Advice and Guidance platform
- **GOV.UK (NHS Test and Trace):** a reporting service that cut average COVID-19 test reporting times across NHS Trusts by 80%
- **Westfield Health:** a first-to-market broker quotation tool, plus the design practice and design system behind it, built from zero
- **EE:** a 31% traffic uplift and 19% conversion lift on Add Mobile, and 29% faster task completion on SIM-only plan selection
- **Sky:** a modernised Broadband & Talk Hub, and contributions to the Polaris design system
